# 使用指南

## 1. 首次配置

1. 打开浏览器 → 右上角溢出菜单（⋯）→ **设置** → **AI 设置**。
2. 打开 **启用 AI 功能**。
3. 选择服务商：
   - **OpenCode Go 预设**：填写在 OpenCode Console 获取的 Key（页面底部有服务政策提示）。
   - **自定义 OpenAI 兼容接口**：填写 Base URL（如 `https://api.openai.com/v1`）。
4. 点击 **API Key** 输入密钥 —— 保存后立即加密，界面只显示“已保存（加密）”。
5. 点击 **获取可用模型**，从列表中选择；也可以直接在 **默认模型** 里手填模型 ID。
6. 点击 **测试 API 连通性** 确认可用。测试会区分 401 / 403 / 429 / 超时 / 网络异常。
7. 按需调整超时、最大输出 Token、流式输出、Agent 最大步数与自动操作权限。

## 2. 打开 AI 面板

溢出菜单（⋯）→ 顶部图标行第 1 个图标（AI）。

面板是底部弹层，包含三个模式：

- **对话**：阅读问答
- **工作**：自主操作浏览器
- **研究**：多网页调研

面板关闭后会话与正在运行的任务都不会丢失；切换标签页或网页也不会。

## 3. 阅读问答

- 直接输入问题 → 发送。若已读取过网页，问题会带上该页面内容。
- 底部 chips：
  - **读取网页**：把当前页面正文读入会话（不写文件）。
  - **总结 / 详细总结**：自动读取当前页再总结。
  - **翻译**：中文页面译成英文，英文页面译成中文，并附关键术语对照。
  - **解释选中内容**：先在网页里长按选中文字，再点此按钮。
  - **提取数据**：输出带来源列的 Markdown 表格。
  - **任务 / 清空 / 复制 / 保存**。
- 生成过程中发送按钮变为停止按钮，点击立即中断。

回答遵守的约束：页面没有写的内容会明说“页面未提供”，不会把推测当作事实；引用时给出标题与 URL。

## 4. 工作模式

在输入框描述任务，例如：

> 打开 Bing，搜索 Android WebView 开发文档，进入官方文档，提取核心 API 说明。

点击发送或控制条上的 **开始**。随后可以看到：

- 顶部状态：当前第几步 / 共几步
- 每条 **步骤**：模型给出的简短理由 + 工具 + 参数
- 每条 **工具**：`OK —` 或 `FAILED —` + 结果 + URL

控制条：

- **暂停**：当前动作完成后停下，按钮变为 **继续**
- **终止**：立即中断网络请求并结束任务

安全相关的行为：

- 提交表单、下载文件、导出 PDF、关闭你自己的标签页、向密码类输入框输入 —— 都会弹出确认框，120 秒不响应按拒绝处理。
- `javascript:`、`file:`、`content:` 等地址直接被拒绝。
- 网页里的文字不会变成指令：页面内容被当作数据，无法改变工具与权限。

## 5. 研究模式

切到 **深度研究**，输入研究主题，例如：

> 最近三个月 IBD 临床研究进展

确认参数后点 **开始研究**：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| 搜索结果数 | 5 | 每次搜索看的条目 |
| 访问网页数 | 6 | 最多真正打开的页面 |
| 研究深度 | 2 | 传递给策略提示的深度 |
| 时间限制 | 600s | 超时即停止 |
| 报告语言 | 跟随系统 | 模型输出语言 |

完成后：

- 报告直接显示在面板中（8 个章节：任务 / 搜索方法 / 来源 / 关键发现 / 结构化对比 / 证据 / 局限性 / 未完成步骤）。
- 自动保存为 `Download/Browser/AI research <yyyyMMdd-HHmm>.md`。
- 报告里的每个来源都来自真实 `extract_markdown` 记录，不会生成假 DOI 或假日期。

## 6. 任务历史

面板中的 **任务** chip 会列出已保存的 Agent / 研究任务：

- **查看**：查看完整报告
- **删除**：删除该记录
- **恢复**（仅未完成的研究任务）：以同一主题重新开始，会重新确认页面状态与权限，不会重放已产生副作用的操作

## 7. 导出

- **保存** chip：如果当前结果是表格，会询问 Markdown / CSV / JSON。
- 研究完成自动保存 Markdown。
- 所有文件都在 `Download/Browser/` 下，可用系统文件管理器打开或分享。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| “API Key 加密失败” | 设置 → AI 设置 → “检查密钥存储”，会显示具体的 Keystore 失败原因；仍失败时请把该提示反馈 |
| “API Key 被拒绝” | 检查 Key 是否过期、是否有对应模型权限 |
| “服务商拒绝该请求 (403)” | 区域/模型策略限制，换模型或换服务商 |
| “请求过于频繁” | 等待额度恢复，或降低并发 |
| “请求超时” | 增大超时设置；长文档可先降低最大输出 Token |
| “模型返回空回复（… finish_reason=length）” | 输出预算被推理消耗，提高最大输出 Token 或换模型 |
| Agent 卡在“规划中” | 网络慢或模型慢，可终止后重试 |
| 元素找不到 | 页面已重新渲染，模型会重新快照；若持续失败说明该元素不可脚本操作 |
| 下载没出现 | 系统下载需要几秒；打开“下载”查看 |

## 9. 资源消耗提示

- 每次 Agent 步骤都会把当前页面摘要发给模型（受 12000 字符限制）。
- 研究任务默认最多 24 步、6 个页面，请留意额度。
- 页面越大，读取耗时越长；超长页面会自动截断并在提示词中标注。

## 11. 第四轮改动（2026-11-12）

### 模式名称

面板三个模式改为：**对话**、**工作**、**研究**（原“Agent / 深度研究”）。

### 对话模式的工具按钮

- 原先「读取页面 / 总结 / 详细总结 / 翻译 / 解释选中内容 / 提取数据」六个按钮，合并为一个 **工具** 按钮。
- 点击 **工具** → 弹出当前工具列表 → 选择要执行的一项。
- 工具的名称与提示词可在 **设置 → AI 设置 → 工具按钮** 中编辑：
  - 点某项 → 编辑名称与提示词；「删除」移除该项；
  - 右上角 **新增工具** → 新建一个自定义提示词工具；
  - 底部 **恢复默认工具** → 回到内置的六项。
- 提示词支持两个占位符：`{选中内容}`（网页中选中的文字）、`{语言}`（翻译目标语言）。
- 内置工具的提示词均为简体中文。

### 工作与研究的限制

- **工作**模式：不再限制步数与时间；仅保留两个防死循环保护——同一失败动作连续 3 次、无法观察页面连续 3 次，以及你随时可以「终止」。
- **研究**模式：不再限制结果数、网页数、深度、步数与时间，参数对话框已移除，输入主题即开始。
- 两个模式都要求模型在**开始前和每一步之前**说明为何这是当前最省时、最省 token 的路径；信息足够就立刻收敛并给出结果，避免无目的试探。

### 报告语言

- 默认 **简体中文**。
- 位置：**设置 → AI 设置 → 报告语言**，可改为任意语言（如 `English`），研究任务的提示词与最终报告都会使用该语言。

## 12. 网页读取方式（2026-11-12）

「读取页面 / 总结 / 翻译」等工具读取网页时，现在走与「保存为 Markdown」完全相同的管线：

1. **等待完全加载**：轮询 `document.readyState`，连续两次为 `complete` 才提取（最多等 15 秒，超时则按当前状态读取，不会失败）。
2. **完整 DOM**：`ArticleExtractor` 克隆整个文档（含导航、表格、图片等），不做裁剪。
3. **同一套转换**：使用 `MarkdownConverter`（即 Markdown 导出的同一实现）把 HTML 转成 Markdown。
4. **读取全文**：不再截断到 24000 字符，全文保留（安全上限 40 万字符，仅防止极端页面耗尽内存）。
5. **超长自动分段精读**：正文超过 6 万字符时，按 4 万字符一段顺序精读，每段先提取与任务相关的事实、数字与引文，最后统一综合。这样长文章的**中间部分不会丢失**。

代价：超长页面会分成多次请求（面板会提示“正在分 N 段精读…”），消耗的 token 比原来多，但内容完整。

## 13. 长回答自动续写（2026-11-12）

- 当模型因为输出上限而停止，但已经写出一部分内容时，面板会**自动请求它接着写**，
  新内容追加在同一条回答后面，不需要你手动点“继续”。
- 续写**没有次数上限**，直到模型自己写完、你点停止，或某次续写没有新内容为止。
- 每次请求仍然只申请设置里的“最大输出 Token”（默认 8192），不会为了长答案一次性索要超大输出。
- 长页面（>6 万字符）仍会先分段精读，每段笔记同样支持续写，保证证据不被截断。

## 14. 长页面（>6 万字符）的处理方式（2026-11-12）

- 正文按 4 万字符分段，**每段都按你点的那个工具的任务处理**：
  - 翻译 → 每段输出该段译文，最后按顺序拼接（不做二次改写，避免译文被转述）；
  - 总结 → 每段输出该段摘要，最后按顺序拼接；
  - 提取 → 每段输出该段的结构化内容。
- 每段结果同样支持“续写”，所以单段很长也不会被截断。
- 面板会显示“正在分 N 段精读…”和“已完成第 i/N 段…”。
- 若某段模型没有产出任何正文，会直接给出明确错误（含 `finish_reason`），而不是空白回答。

## 15. 不再限制请求时长（2026-11-12）

- 设置 → AI 设置 → **请求超时（秒，0 = 不限制）**，默认 **0**，即不限制单次请求时长。
- 旧版本默认是 120 秒，升级后会自动迁移成 0（只迁移“从未改过”的值）。
- 翻译这类长输出不会再被超时打断；需要中止时点面板的“停止”，会立即断开连接。
- 分段翻译现在边生成边显示，并提示“已完成第 i/N 段…”。

## 16. 长页面部分失败的显示方式（2026-11-12）

- 长页面分段处理时，**某一段失败不会清空已经完成的内容**。
- 失败段落会重试一次；仍失败则跳过，并在结果末尾用引用块列出：
  “以下段落未能完成，结果可能不完整：第 N 段：原因”。
- 只有所有段落都没有产出时，才会整体报错。
- 每段大小调整为 2 万字符，进度提示更频繁（“已完成第 i/N 段…”）。
